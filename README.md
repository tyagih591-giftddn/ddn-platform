# DDN – District Delivery Network

Version 1: Delivery booking only
Launch area: Indirapuram, Ghaziabad, Uttar Pradesh

## Project structure
- frontend/ — customer delivery booking web app starter
- backend/ — API starter
- admin/ — admin panel starter
- rider/ — rider app starter
- docs/ — project notes

## Suggested free pilot architecture
Customer booking → Backend API → PostgreSQL → Admin Panel → Rider App

## Deployment plan
- Frontend: Cloudflare Pages
- Backend: Render free tier
- Database: PostgreSQL

No domain or hosting is included in this starter ZIP.
